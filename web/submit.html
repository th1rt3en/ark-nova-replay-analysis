Open this game with the browser extension

Table is known to us, but its log has not been collected yet. You can open it anyway with our browser extension, which takes the log from your Board Game Arena session:

  1. Install the extension for your browser:
    • Chrome / Chromium browsers (Chrome Web Store)
    • Firefox (Firefox Add-ons)
  2. Open the replay of this game on Board Game Arena (you need to be logged in there):
  3. The extension adds a button to that page: click it to open the replay on this website.
